Data sources Papers, author records and citation counts come from Scopus. Membership of the university comes from the AAU faculty roster, never from Scopus.
Why the gate exists
A sweep by author returns everything that person published anywhere. Asking for one professor's papers returns 53, and only 30 print an AAU address. Without the gate the census re-inflates by hundreds of papers belonging to other universities.
Why a name can be missed
The roster writes Al-Takhayneh, Scopus prints Al-Tkhayneh. One vowel apart. Exact matching misses it and a professor with 39 papers disappears, so near-misses are checked separately before anyone is called new.
What a healthy run looks like
Run it twice on unchanged data and the second run reports nothing new. If it invents an addition, the papers are being matched wrongly, and that is a bug rather than a discovery.
